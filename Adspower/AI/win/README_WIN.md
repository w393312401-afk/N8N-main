# 🪟 Windows 用户启动说明

## 快速启动（推荐）

1. 打开 AdsPower 桌面客户端
2. 双击本目录下的 `start_server.bat`
3. 等待安装依赖（首次约 2-5 分钟）
4. 看到 `Uvicorn running` 字样即代表启动成功

---

## 验证启动成功

打开浏览器，访问：

```
http://127.0.0.1:8000/
```

看到 `"status": "All-in-One API is running"` 即为正常。

---

## 常见问题

| 问题 | 解决方法 |
|------|---------|
| 双击窗口一闪而过 | 右键 → 以管理员身份运行 |
| `pip` 不是内部命令 | 重新安装 Python，勾选"Add to PATH" |
| 端口 8000 被占用 | 修改 `.env` 文件中的 `SERVER_PORT` 为其他端口（如 8001） |

---

## 停止服务

直接关闭启动的命令行窗口即可停止服务。
