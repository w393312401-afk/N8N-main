# ⚙️ Notion 24h Auto Gen System — 配置说明

为了确保整个工作流能够顺利跑通，请根据您的环境修改以下配置。

---

## 1. 核心参数（在 n8n 的"全局设置"节点中修改）

所有核心参数均可以在 **`全局设置 (Config)`** 节点中修改。这是一个 `Set` 节点，位于工作流的最左侧。

| 变量名 | 说明 | 默认值 |
| --- | --- | --- |
| `BASE_VIDEO_DIR` | 本地存储图片和视频的根目录（需要有写入权限） | `/Users/fly/Desktop/AI_video` |
| `API_BASE_URL` | AI 生成服务的 API 地址 | `http://127.0.0.1:8000` |
| `notion_db_task_id` | **任务数据库** 的 Notion ID | `3054062a...` |
| `notion_db_account_id` | **账号数据库** 的 Notion ID | `3054062a...` |

### 如何修改？
1. 在 n8n 画布中**双击** `全局设置 (Config)` 节点
2. 在 `Values` 列表中找到对应的 `Name`
3. 修改 `Value` 值后保存

---

## 2. 凭证设置（Credentials）

本工作流使用两个 Notion API 连接，请检查您的凭证：

- **读取凭证 (Reader)**: 用于`获取任务`、`获取账号`
- **写入凭证 (Writer)**: 用于`更新账号状态`、`任务完成`、`回写错误`

> [!IMPORTANT]
> 如果您没有已有凭证，需要：
> 1. 在 n8n 左侧菜单 **Credentials** 中新建一个 Notion API 凭证
> 2. 回到工作流，双击所有 **Notion 节点**
> 3. 在 `Credential for Notion API` 下拉框中，选择您自己创建的凭证

---

## 3. 环境准备（Prerequisites）

运行前请确保：

- [ ] **AdsPower 客户端**已打开，且目标浏览器环境已存在（默认 `kxplh32`）
- [ ] **Python 3** 已安装，且运行过依赖安装（启动脚本会自动执行）
- [ ] **本地目录存在**：`BASE_VIDEO_DIR` 指定的父目录（子目录会自动创建）
- [ ] **AI 服务运行中**：`http://127.0.0.1:8000` 可访问（即已启动 AI 服务）
- [ ] **Notion 权限**：您的 Notion Integration 已被邀请至上述两个 Database 页面
- [ ] **ffmpeg 已安装**（如需使用视频合并功能）

---

## 4. 调试建议

- 首次运行时，点击工作流底部的 **Executions** 标签页，观察实时运行日志
- 如果遇到红色报错，检查报错节点的输出信息
- 查看服务日志：`Adspower/AI/server.log`

---

## 5. AI 服务配置（core/config.py）

> ⚠️ 以下为技术配置，普通用户无需修改

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `MAX_WAIT_SECONDS` | `60` | 生成任务最大等待时间(秒) |
| `OUTPUT_DIR` | `~/Desktop/AI生成` | 输出目录，可通过环境变量 `ADSPWR_OUTPUT_DIR` 覆盖 |
| `PAGE_LOAD_TIMEOUT` | `60000` | 页面加载超时(毫秒) |
| `DEFAULT_USER_ID` | `kxplh32` | 默认 AdsPower 环境 ID |
| `DEFAULT_PORT` | `50325` | 默认 AdsPower API 端口 |
