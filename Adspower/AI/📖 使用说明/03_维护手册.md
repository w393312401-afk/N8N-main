# 🔧 维护指南 — AdsPower All-in-One API

> 本文档面向后续维护者，说明如何扩展功能、排查问题和保持代码质量。

---

## 一、如何排查问题

### 1.1 常见问题速查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------| 
| `AdsPower 启动失败` | AdsPower 客户端未打开 | 启动 AdsPower 桌面客户端 |
| `超时未检测到视频` | 平台 UI 改版或网络慢 | 更新 `core/ui_selectors.py`，或增大 `core/config.py` 中的 `MAX_WAIT_SECONDS` |
| `429 Too Many Requests` | Gemini 并发请求 | `gemini_lock` 已自动限制，等待上一个任务完成 |
| `Send button disabled` | 文件上传未完成 | 检查文件路径是否正确，增加等待时间 |
| 图片/视频下载为空 | blob URL 过期 | 检查网络连接，重试任务 |

### 1.2 查看日志

日志文件位置：`Adspower/AI/server.log`

```bash
# macOS - 实时查看日志
tail -f /Users/fly/Desktop/N8N-main/Adspower/AI/server.log

# macOS - 搜索错误
grep "❌" /Users/fly/Desktop/N8N-main/Adspower/AI/server.log | tail -20
```

### 1.3 案发现场截图

当关键 UI 元素找不到时，系统会自动保存截图到：
```
~/Desktop/AI生成/Errors/error_YYYYMMDD_HHMMSS.png
```

## 二、如何修改 UI 选择器

当 AI 平台更新 UI 后，浏览器自动化可能失败。修复方法:

1. **定位问题**: 查看 `server.log` 中的 `❌` 错误和截图路径
2. **更新选择器**: 编辑 `core/ui_selectors.py` 中对应平台的选择器
3. **测试**: 重启服务后调用对应 API 验证

## 三、如何添加新的 AI 平台服务

以 **添加 Midjourney 视频生成** 为例，只需 3 步:

### 第 1 步: 创建服务文件 (`core/services/midjourney.py`)

```python
from config import MAX_WAIT_SECONDS, OUTPUT_DIR
from models import VideoRequest
from utils.logger import log

def _generate_video_midjourney(req: VideoRequest):
    result = {"status": "failed", "video_url": None, "message": ""}
    # ... 你的 Midjourney 自动化逻辑 ...
    return result
```

### 第 2 步: 在 `core/app.py` 注册路由

```python
from services.midjourney import _generate_video_midjourney

@app.post("/generate_video_midjourney")
def generate_video_mj(req: VideoRequest):
    return _generate_video_midjourney(req)
```

### 第 3 步: (可选) 更新统一路由

```python
@app.post("/generate_video")
def generate_video_unified(req: VideoRequest):
    model_name = req.model.lower() if req.model else ""
    if "veo" in model_name:
        return _generate_video_google_fx(req)
    elif "midjourney" in model_name:          # ← 新增
        return _generate_video_midjourney(req) # ← 新增
    else:
        return _generate_video_grok(req)
```

> ✅ **无需修改** `config.py`、`utils/`、其他 `services/` 文件。

## 四、代码修改规范

### 文件职责

| 层 | 文件 | ✅ 应该包含 | ❌ 不应该包含 |
|---|------|-----------|-------------|
| 配置层 | `core/config.py` | 常量、超时值、路径 | 业务逻辑 |
| 模型层 | `core/models.py` | Pydantic 模型定义 | 数据处理逻辑 |
| 工具层 | `core/utils/*.py` | 通用、可复用的函数 | 平台专属逻辑 |
| 服务层 | `core/services/*.py` | 特定平台的业务逻辑 | 路由定义 |
| 入口层 | `core/app.py` | 路由注册、中间件 | 具体业务实现 |

### 依赖方向（禁止循环引用）

```
config.py → utils/ → services/ → app.py
            ↑
       ui_selectors.py
```

## 五、部署检查清单

启动前确认:

- [ ] AdsPower 客户端已打开
- [ ] 目标浏览器环境已存在（默认 `kxplh32`）
- [ ] Python 3 已安装上述所有依赖
- [ ] `OUTPUT_DIR` 目录可写（`~/Desktop/AI生成`）
- [ ] `ffmpeg` 已安装（如需使用视频合并功能）
