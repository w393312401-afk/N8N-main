# 📚 AdsPower All-in-One API 项目说明书

> **版本**: 2.0 (模块化重构版)  
> **更新日期**: 2026-03-05  
> **入口文件**: `app.py`  
> **统一服务地址**: `http://127.0.0.1:8000`

---

## 一、项目简介

本项目是一套基于 **FastAPI + Playwright + AdsPower** 的自动化 API 服务，通过浏览器自动化操作来调用 Google、Grok、Gemini 等 AI 平台的能力，实现视频生成、图片生成和智能分析功能。

主要在 **n8n 工作流** 中作为后端服务被调用。

## 三、可用模型一览

### 🎬 视频生成模型

| 模型名称 | 平台 | 说明 |
|----------|------|------|
| `Veo 3.1` | Google FX | 默认视频模型，支持参考图 |
| `Grok` | xAI Grok | 任何非 Veo 名称自动路由到 Grok |

> 💡 `/generate_video` 会根据 `model` 字段自动路由：名称包含 "veo" → Google FX，其他 → Grok。

### 🖼️ 图片生成模型

| 模型名称 | 平台 | 说明 |
|----------|------|------|
| `Nano Banana 2` | Google FX (Imagen) | 默认图片模型 |
| `Imagen 3` | Google FX (Imagen) | 高质量图片生成 |

### 🧠 Gemini 分析模型

| 模型名称 | 说明 |
|----------|------|
| `Gemini Advanced` / `pro` | 默认分析模型，最强能力 |
| `Gemini 2.0 Flash` / `flash` | 快速响应模型 |
| `Gemini 2.0 Flash Thinking` / `thinking` | 深度思考模型 |

### 📐 画面比例

| 比例参数 | 方向 | 适用 |
|---------|------|------|
| `16:9` | 横屏 | 视频/图片 |
| `9:16` | 竖屏 | 视频/图片 |
| `1:1` | 方形 | 图片 |

## 四、快速启动

### Windows
1. 确保 **AdsPower 客户端**已打开
2. 双击 `Adspower/AI/【Windows】启动AI服务.bat`
3. 服务运行在 `http://127.0.0.1:8000`

### macOS
1. 确保 **AdsPower 客户端**已打开
2. 双击 `Adspower/AI/mac/后台24小时运行服务.command`

## 五、API 接口速查

> **统一请求地址**: `http://127.0.0.1:8000`

| 接口路径 | 方法 | 功能 |
|---------|------|------|
| `/` | GET | 健康检查 |
| `/generate_video` | POST | 视频生成（自动路由 Veo/Grok） |
| `/generate_images_batch` | POST | 批量图片生成 |
| `/analyze/json` | POST | Gemini 文件分析 |
| `/merge_videos` | POST | 视频合并 |
| `/environments` | GET | 列出 AdsPower 环境 |

## 六、配置说明

所有全局配置集中在 `core/config.py`（⚠️ 修改需谨慎）：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `MAX_WAIT_SECONDS` | `60` | 生成任务最大等待时间(秒) |
| `OUTPUT_DIR` | `~/Desktop/AI生成` | 视频/图片保存目录 |
| `DEFAULT_USER_ID` | `kxplh32` | 默认 AdsPower 环境 ID |
| `DEFAULT_PORT` | `50325` | 默认 AdsPower API 端口 |

详细配置说明见 → [02_配置说明.md](./02_配置说明.md)
