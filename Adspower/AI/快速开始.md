# 🚀 快速开始 — AdsPower AI 服务

> 📖 **这是小白专属指南！** 按步骤操作，5 分钟即可启动服务。

---

## 第一步：确认前置条件

在启动服务之前，请先核对以下 3 点：

- [ ] ✅ **AdsPower 桌面客户端已打开**（必须，否则服务无法工作）
- [ ] ✅ **已安装 Python 3**（没有的话去 https://www.python.org 下载）
- [ ] ✅ **已安装 ffmpeg**（没有的话 Mac 用户运行 `brew install ffmpeg`）

---

## 第二步：启动服务

### 🍎 macOS 用户

**方式一（推荐）：双击启动**

在 Finder 中找到这个文件，直接双击：

```
AI/mac/服务管理.command
```

出现菜单后按 **1** 然后回车，服务即启动。

---

**方式二：终端命令行**

```bash
cd /Users/fly/Desktop/N8N-main/Adspower/AI/mac
bash 服务管理.command
```

---

### 🪟 Windows 用户

在文件资源管理器中找到这个文件，**直接双击**：

```
AI\win\start_server.bat
```

> 💡 如果双击后窗口一闪而过，请右键选择"以管理员身份运行"

---

## 第三步：确认服务正常

服务启动后，打开浏览器访问：

```
http://127.0.0.1:8000/
```

如果看到如下内容，说明服务运行正常 ✅：

```json
{
  "status": "All-in-One API is running",
  "ads_power_api_reachable": true
}
```

---

## 常见问题 FAQ

| 问题 | 解决方法 |
|------|---------|
| 双击 `.command` 没反应 | 右键 → 选择"打开" → 点击"允许" |
| `ads_power_api_reachable: false` | 打开 AdsPower 桌面客户端 |
| 服务启动后浏览器打不开 | 检查端口 8000 是否被占用，重启电脑后再试 |
| 生成视频/图片超时 | AI 平台响应慢属正常，可适当增大 `.env` 中的 `MAX_WAIT_SECONDS` |
| 看不到生成文件 | 默认保存在 `~/Desktop/AI生成/` 文件夹 |

---

## 生成内容保存在哪？

所有生成的视频和图片默认保存在：

- **Mac**：`~/Desktop/AI生成/`（即桌面上的"AI生成"文件夹）
- **Windows**：`C:\Users\你的用户名\Desktop\AI生成\`

> 想修改保存位置？编辑项目根目录 `.env` 文件中的 `ADSPWR_OUTPUT_DIR` 那一行。
